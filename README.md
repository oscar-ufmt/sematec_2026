# SEMATEC 2026 - Minicurso de Redes

Este repositório contém o material e as orientações para o minicurso de Redes realizado na SEMATEC 2026.

## Sobre o Minicurso
O curso aborda conceitos fundamentais de redes, com foco em implementação e testes. Como parte do aprendizado prático, utilizamos ferramentas de hardware para entender processos de verificação.

---

**Exemplo Prático:** Verificação Comportamental de uma Unidade Lógica Aritmética (ULA).

## Ferramentas Utilizadas (Ambiente de Desenvolvimento)

Para acompanhar os exemplos de verificação do material de apoio, recomendamos as seguintes versões de software (compatíveis com o minicurso):

| Software | Versão | Link de Download |
| :--- | :--- | :--- |
| **Quartus II (Web Edition)** | **13.0sp1** | [Download Altera 13.0](https://www.altera.com/downloads/fpga-development-tools/quartus-ii-web-edition-design-software-version-13-0sp1-windows) |
| **ModelSim (FPGA Edition)** | **17.0** | [ModelSim Starter Edition](https://fpgasoftware.intel.com/17.0/?edition=lite) |

**Por que estas versões?**
*   **Quartus 13.0:** Versão estável que não exige licença paga (Web Edition).
*   **ModelSim 17.0:** Utilizado por possuir representação em ponto flutuante, essencial para análises mais complexas.
