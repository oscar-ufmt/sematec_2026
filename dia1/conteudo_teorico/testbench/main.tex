\section{Objetivos}
%----------------------------------------------------------------------------------------

\begin{frame}
	\frametitle{Objetivos}
	
\begin{itemize}
	\item \textbf{RTL no Quartus:}
	\begin{itemize}
		\item Entender os conceitos e princípios do RTL (Register-Transfer Level) e como ele é aplicado no software Quartus II.
		\item Aprender a utilizar o Quartus II para realizar a descrição em RTL de circuitos digitais.
		\item Explorar as ferramentas e recursos disponíveis no Quartus para desenvolver designs em RTL e realizar simulações para verificação.
	\end{itemize}
	
\item \textbf{Testbench:}
\begin{itemize}
	\item Definir o conceito de testbench e sua importância no processo de verificação de circuitos digitais.
	\item Configurar e utilizar testbenches no Quartus II para simular designs em VHDL.
	\item Construir testbenches eficazes para validar o comportamento dos circuitos implementados no FPGA DE0 Nano.
\end{itemize}

\item \textbf{ModelSim:}
\begin{itemize}
	\item Introdução ao ModelSim como uma ferramenta de simulação de circuitos digitais.
	\item Explorar as funcionalidades do ModelSim para realizar simulações precisas e eficientes de designs VHDL.
	\item Aprender a interpretar os resultados das simulações no ModelSim para verificar o funcionamento correto dos circuitos.
\end{itemize}	
	
	
\end{itemize}
	
	
	
	
\end{frame}

\section{Testbench}
%----------------------------------------------------------------------------------------
\begin{frame}{Verificação comportamental}
	
	
	
	\begin{block}{Testbench}
		\justifying
		A verificação funcional de arquiteturas VHDL é realizada por meio de simulação utilizando um banco de testes. Um banco de testes é um sistema VHDL que instancia o sistema a ser testado como um componente e então gera os padrões de entrada e observa as saídas. O sistema em teste é frequentemente chamado de dispositivo em teste (\textbf{DUT}) ou unidade em teste (\textbf{UUT}). Bancos de testes são utilizados apenas para simulação, então podemos utilizar técnicas de modelagem abstrata que não são sintetizáveis para gerar os padrões de estímulo.
	\end{block}
